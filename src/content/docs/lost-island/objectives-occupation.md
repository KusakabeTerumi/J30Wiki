ロストアイランドのアライアンス攻略では、**領土をつないで拠点を占領すること**が基本になります。各施設の役割を知り、攻撃条件と報酬を確認して進めましょう。

## 拠点を探す

ロストアイランドの主な拠点は、**豊穣の木、奇観、生息地、巣、トンネル、港**などです。

蟻塚外画面のマップ・拠点一覧から分布を確認できます。拠点のアイコンを選ぶと座標が表示され、座標をタップするとその場所へ移動できます。

## 拠点を占領する基本手順

1. 自盟のアライアンス監視哨が攻撃対象の拠点に接していることを確認します。
2. 拠点の**守衛部隊**を撃破します。
3. 拠点の**全耐久値**を破壊します。
4. 占領後、対象の「説明」でバフや報酬を確認します。

監視哨が接していない拠点は、攻撃できません。また、攻撃可能な条件や耐久値は拠点ごとに確認してください。

## 敵アライアンスが占領した拠点の場合

敵アライアンスや敵陣営の占領拠点を攻撃する場合、**敵リーダーの守衛部隊→NPC守衛部隊→耐久値の破壊**という順序が案内されています。対象を攻める前に、戦力と参加人数を確かめましょう。

## トンネルの争奪時に注意すること

ゲーム内のルールでは、**トンネルの最後の耐久値1点を破壊したアライアンスが占領できる**と案内されています。他勢力も同じトンネルを狙っている場合、守衛を倒しただけで占領できるとは限りません。

トンネルに攻撃するときは周囲の別アライアンスの動きも確認し、占領の競合を想定しましょう。

## 拠点ごとの主な役割

| 拠点 | 主な役割 |
|---|---|
| 豊穣の木 | 中央の重要施設。バフがあり、その地域の中立領土に移転できる。占領状況はシーズンリワードに影響する |
| 奇観 | 地域の中心施設。バフがあり、その地域の中立領土に移転できる。占領数はシーズンリワードに影響する |
| 生息地 | 地区の中心施設。バフがあり、その地区の中立領土に移転できる |
| 巣 | 占領により各種バフを得られる施設 |
| トンネル・港 | ほかの地域へ進むための通路となる施設 |

施設により得られる効果は異なります。占領前には対象施設の「説明」を確認してください。

## 初回占領リワードと占領中の効果

占領するとバフやリワードを得られる場合がありますが、**初回占領リワード**には条件があります。ゲーム内の説明では、初回占領したアライアンスに付与され、**「陣営拠点」では初回占領リワードを得られない**とされています。

シーズン終了時の報酬は[シーズンの報酬とレスキュー](../rewards-rescue/)を参照してください。
