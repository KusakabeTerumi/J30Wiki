初期配置は、地形だけでなく周辺のアライアンスや参加できる人数を合わせて考えると比較しやすくなります。以下は配置を選ぶための参考であり、J30の配置を決定するものではありません。

## 比較するポイント

| 観点 | 比較すること |
| --- | --- |
| 周辺勢力 | どのアライアンスと隣接するか。話し合いの余地があるか。 |
| 進路 | 目標の施設へ向かう経路や、他の勢力と競合する場所はどこか。 |
| 活動時間 | 自分たちと周辺勢力の活動時間がどの程度重なるか。 |
| 参加人数 | 建設や戦闘に無理なく参加できる人数で進められるか。 |
| 消耗 | 進路を確保するために、どの程度の戦闘が必要になりそうか。 |

## 周辺勢力も含めて判断する

競合する勢力が少なくても、必ず平和になるとは限りません。相手の戦力や方針によって状況は変わります。地形の印象だけで結論を出さず、外交と参加しやすさも合わせて考えましょう。
